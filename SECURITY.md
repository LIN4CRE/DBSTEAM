| Version | Supported          |
| ------- | ------------------ |
| 1.0.x   | :white_check_mark: |

## Reporting a Vulnerability

Security and privacy are taken with the utmost seriousness across the DBSTEAM platform. Because DBSTEAM handles sensitive game library metadata, cloud save backups, and credentials:

1. **Do not create public GitHub issues for security vulnerabilities.**
2. Send all security reports directly to: `davidlinacre@hotmail.co.uk` with the subject tag `[SECURITY: DBSTEAM]`.
3. Provide a detailed summary of the vulnerability, reproduction steps, proof of concept, and affected environment.
4. Reports are acknowledged within 24-48 hours with coordinated triage and patch deployment.
